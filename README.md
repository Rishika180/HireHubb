# HireHubb – Smart Job Hiring Platform

HireHubb is a full-stack MERN Job Portal platform where students can explore and apply for jobs, and recruiters can post and manage job listings.
 Features:-
* Student
User Authentication (Signup/Login)
Browse Jobs
Search Jobs
Apply for Jobs
Update Profile
View Applied Jobs

* Recruiter

Create Company Profile
Post New Jobs
View Applicants
Manage Job Listings

* Tech Stack
1. Frontend:-
React.js
Vite
Tailwind CSS
Redux Toolkit
Axios
React Router DOM

2. Backend:-

Node.js
Express.js
MongoDB (Atlas)
Mongoose

# JWT Authentication
Bcrypt
Multer (File Upload)
